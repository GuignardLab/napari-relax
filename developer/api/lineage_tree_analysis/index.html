    get_sublineage(cell, lT) staticmethod ¶

    Score the nodes of the lineage that contains a cell.

    Nodes in the subtree of cell and its ancestors get 1; nodes in other branches get one more than the number of divisions between cell and their branching point.

    Parameters:

    Name Type Description Default
    cell int

    ID of the cell.

    		 required
    lT LineageTree

    The LineageTree.

    		 required

    Returns:

    Type Description

    thread_worker() ¶

    Timepoints after the crop time or with a single cell are skipped.

    Yields:

    Type Description
