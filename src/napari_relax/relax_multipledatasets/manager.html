LineageTree Manager

Create or load a Manager
  • Managers can be saved and loaded from this component
  • All layers that contain a LineageTree can be added to the manager with the press of Create a Manager from existing layers.
  • Any LineageTree that is not desired can be removed with Right Click -> Remove Embryo
  • The time resolution of any dataset loaded into a manager can be changed by Right click -> Change Time Resolution

Full documentation: guignardlab.github.io/napari-relax
