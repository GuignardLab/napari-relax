Configuration
  • Choose timepoints by range or specify them directly to compare all sublineages spawned at those times (Levels of Comparison).
  • Select the cropping time of the lineages and press Enter.
  • Choose the appropriate approximation (more info in the approximation button's tooltip).
  • Filter out which lineages should be compared, by selecting the appropriate labelled predecessors. With no selection, all lineages starting at the first timepoint are compared.
  • Comparison start by pressing Run Comparisons and can be stopped at any time by pressing Stop Processing.
