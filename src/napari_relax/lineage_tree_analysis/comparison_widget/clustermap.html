This widget focuses on lineage comparisons in one embryo.

There are 2 tabs used for lineage comparisons:

  • Configuration tab: The user may decide on the different starting points the comparisons will start from in the form of a range. Then they can decide if the trees used will be pruned so that their final timepoint is not the end of the dataset. Then they can decide which roots are going to be used.
  • Inspection tab: The user can interact with the plot and select specific comparisons to see their result on the viewer. Using the scrollbar, they may choose which comparisons they want to inspect if they decided to calculate multiple times.
