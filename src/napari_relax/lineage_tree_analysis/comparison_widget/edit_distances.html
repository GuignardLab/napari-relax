Edit Distances:

  • Mini Tree: Mini Tree uses only the division patterns without taking into account the chain length (cell lifetime).
  • Reduced Tree: Simple Tree converts each chain into a node with length equal to the cell lifetime..
  • Normalized Reduced Tree: The Normalized Tree is similar to the Simple Tree, but its matching function is adjusted. In this version, two cells with long lifetimes and relatively small differences are assigned a smaller distance. So, relatively small loss in synchonisity is not taken into account.
  • (Recommended) Downsampled Tree: Downsampled Tree converts the tree to nodes of n length (where n is the downsample size). This method is very accurate and fast, and it is recommended for use when running comparisons live on napari.For downsample 1 it becomes identical to full tree.
  • (Not recommended) Full Tree: Directly compares two trees with each other. This is the most accurate method, but it is extremely slow. Do not use in napari.
