Explore and Relabel Lineage Data

The Lineage Viewer Controls:

  • Left click: Select a sublineage of a node.
  • Double Left click: Go to the spawn time of the clicked node and select its sublineage.
  • Mouse wheel: Zoom in or out of a lineage.
  • Right click and drag: Pan the Lineage Viewer.
  • Z: Reset the view.
  • Slider: Iterate through different lineages.
  • Cell ID selector: Type a cell ID and press Enter or Go to jump to its lineage.

Shift-Right click on the Viewer to select nodes. This will also show the corresponding lineage if it exists.

Show/hide, select or save lineages using the corresponding buttons.

Node size, edge size and font size of the Lineage Viewer: File > Preferences > ReLAX.
