Explore and Relabel Lineage Data The Lineage Viewer Controls:
  • Double left click: Move the Napari Viewer to the spawn time of the selected cell.
  • Mouse wheel: Zoom in or out of a lineage.
  • Right click: Pan the Lineage Viewer.
  • Z: Reset the view.
  • Left click: Select a sublineage of a node.
  • Double Left click: Go to the time the node clicked was spawned and select its sublineage.
  • Slider: Itereate through different lineages.
Shift-Right click on the Viewer to select nodes. This will also show the corresponding lineage if it exists. Show/hide, select or save lineages using the corresponding buttons
