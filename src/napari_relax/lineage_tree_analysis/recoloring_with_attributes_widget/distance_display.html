This component focuses on quick analysis and recoloring of the dataset.

This part of the plugin is seperated on 2 parts: One focusing on recoloring/resizing the points on the napari viewer that correspond to lineages starting from tp 'n' according to their uted. The second part is focused on premade analysis and it is able to read all attributes (even custom ones) from a file and recolor all the clones in both the lineage and napari viewer according to these.

  • Comparisons component: First using the interactive plot select the starting timepoint of the lineages to be compared and press recolor. After that choos if you want to project on size or on color. Then pressing Ctrl + Right Click the program will automatically compare the lineage selected with the rest and show it on the viewer.
  • Coloring component: Select the attribute you want to use for coloring. Select the colormap you like most. Select if you want to propagate existing values to nodes that do not have any. Press color nodes to color the viewer and the lineages. Go back to the Progeny Selection plugin to inspect the lineages.
